`specialist_inputs.incident_rca_origin: true`, so no existing task type's review changes; both functions are
standalone and unreferenced until a human or Orchestrator calls them.

- No runtime change for any task not originating from this handoff.
- **False-block cost of condition 9**: matching at any directory depth means a fixture under
  `tests/fixtures/manifests/` or application code in an `iam/` or `policies/` directory blocks an
  `incident_rca_origin` task and escalates to a human. Safe direction, stated in the design.
- **Blocking-standard numbering is cross-ticket state**: C1 took 7, C2 took 8, C3 takes 9. An implementer must
  re-check the real maximum on `origin/main` at implementation time; C4-C8 must do the same.

  CD-on-merge is enabled for the repository.

## Unknowns / material unknowns

1. **`has_existing_task_branch` population is a caller-applied convention.** Nothing in `orchestrator.md`
   invokes the provenance or duplication lookups; a caller can pass `False` without running them. Duplicates
   remain possible when no shared state exists. Disclosed, not closed.
2. **Keyword exclusion is evadable** by a qualifying verb plus an infra noun in none of the lists; condition 9
   is the real control for the infra subset, and its path set is best-effort and layout-dependent.
3. **`target` discovery usually falls through to service-name-only** (a backtick-quoted symbol is rare in real
   RCAs), and no mechanism resolves a symbol to a file. A 128-character whitespace-free instruction-like
   string passes the symbol form.
4. **Family gap**: C1 and C2 take `target` from report evidence and neither validates it; C3 adds the helper
   for itself only. Retrofitting is flagged for follow-up.
5. **Upstream gap in `incident-rca`'s `report-template.md`**: its safe-output enumeration omits the Executive
   summary, Conclusion and the Preventive `Action`/`Notes` cells while claiming no escaping is needed for
   anything else. Outside this ticket.
6. **Report shape varies**: the gold example's Preventive table has 3 columns (no `Notes`), the template has
   5. Real-world shapes are unvalidated.
7. **Keyword precision/recall is unvalidated** against real Preventive-action phrasing.
8. Resolved this analysis: no test in the repository pins the Blocking-standard condition count or text
   (grepped tests, scripts and shared docs); `SKILL.md`'s condensed Blocking-standard prose is already stale
   for conditions 6-8, pre-existing and disclosed by C1 and C2.
