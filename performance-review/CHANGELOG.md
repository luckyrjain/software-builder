# Changelog — performance-review

## 1.0.0 — 2026-08-22

### Added

- Initial release: reviews code, a query, or a service for algorithmic complexity, database access
  behavior, N+1 query patterns, caching correctness, memory patterns, concurrency hazards, connection
  pool sizing, and downstream fanout, via a linear Inputs → Analyze → Report pipeline producing
  `PERFORMANCE_REVIEW_REPORT.md`.
